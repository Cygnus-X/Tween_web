Privacy Policy

Last updated: August 30, 2026

This policy covers Tween, the Mac app for designing vector shapes and motion graphics, published by Cygnus-X. It explains what data Tween collects, why, and what it never touches.

The short version

Tween sends a small, anonymous usage event — which export or feature you used, or whether the app hit an error, hung, or crashed — tagged only with a random install ID. It never sends your documents, file names, shape data, images, or anything that identifies you personally. There is no account, no login, and no third-party analytics SDK.

What we collect

Every event is the same three fields, sent as one anonymous request when you use an export or feature, or when the app detects a known error, hang, or crash:

FieldWhat it is
platformA short tag identifying the event — e.g. which export format (PDF, PNG, SVG, video, or a code-export platform) or feature was used, or an error/crash/hang signal.
installIDA random identifier generated once per install and stored locally. It is not tied to your name, email, Apple ID, or device identifier.
timestampWhen the event happened.

Specifically, this covers:

  • Export usage — that you exported a PDF, PNG, SVG, or video, or generated code for a given platform (SwiftUI, Android, Compose, Flutter, etc.), so we can see which formats people actually use.
  • Feature adoption — the first time you open certain tabs or use certain features (like gradient fills or SVG import), logged once per install.
  • Known errors — that a specific export or import action failed, so we know something needs fixing.
  • Crash/hang signals — a proxy flag indicating the previous session didn't end cleanly, or that the app's main thread stopped responding for several seconds. This is a heuristic, not a full crash report — it carries no stack trace, log, or document content.

We do not collect your name, email address, location, IP-linked identity, document contents, file paths, shape or layer names, images you import, or any In-App Purchase payment details — those are handled entirely by Apple and never reach us.

How it's used

Solely to understand which features and export formats are actually used, and to catch errors, hangs, or crashes we wouldn't otherwise hear about — there's no way for someone to email us a crash report from inside a sandboxed Mac app. The data lands in a private spreadsheet we use for our own product decisions. It is never sold, and never shared with advertisers or data brokers.

Where it goes

Events are sent directly from the app to a private Google Apps Script endpoint we control, which appends each event as a row in a Google Sheet only we have access to. No third-party analytics vendor or SDK is involved.

Your choices

  • There is nothing to opt into — no account is ever created.
  • Because the install ID isn't linked to your identity, we have no way to look up or delete data tied to a specific person on request — it isn't attributable to you in the first place.
  • Tween works fully offline for drawing and editing; only export/feature events and the rare error/crash signal ever attempt a network request, and a failed or blocked request never affects the app's behavior.

In-App Purchase

Tween's one-time "Unlock Tween" purchase is processed entirely by Apple through StoreKit. We never see your payment information — no card number, billing address, or Apple ID email. Apple's own privacy policy governs that transaction.

Children's privacy

Tween is not directed at children and does not knowingly collect information from children. The anonymous usage data described above carries no age or identity signal of any kind.

Changes to this policy

If what we collect changes, we'll update this page and the "Last updated" date above. Material changes will also be reflected in the app's release notes.
