How it works

Three steps. One canvas. Real output.

01 — Draw

A full Bezier pen tool — or just sketch

  • Curves, corners, and smooth points
  • Exact numeric X/Y and segment length per point
  • Rectangles, circles, polygons with an N-point star switch, and arcs/pie slices
  • Free Draw: sketch freehand and it's auto-smoothed into a clean curve
  • Smooth Lines turns every corner of a selection into a curve in one tap
  • Solid or gradient fills, stroke width, caps, dashes
  • Text and images, snap-to-grid, device-size guides
  • Smart alignment guides that snap to other layers or the canvas center
  • Import an SVG, image, or SF Symbol — trace any of them into real points, drag a file onto the canvas, or ask the built-in AI assistant to build it for you
02 — Animate

Move, fade, spin, ship

  • Move, rotate, scale, fade, or 3D-flip any object
  • A draggable rotation pivot for precise spins
  • Stroke-reveal with duration, direction, looping, and Linear/Ease In/Ease Out/Ease In-Out timing
  • Live scrub timeline, layers with hide/lock/reorder
  • Export the whole animation as transparent ProRes video
03 — Export

Code for where you build

  • SwiftUI Shape struct or raw Path snippet
  • SVG, HTML, JS Canvas, React, or React Native
  • PDF and PNG (1x/2x/3x) for anything else

Everything else

Small details that add up.

Gradient fills

Linear and radial, with a free-form reorderable stop list — add, remove, and recolor stops directly on the canvas.

Per-color opacity

Every fill, stroke, and text color has its own opacity slider — carried through to every export format, including SVG and Canvas.

Layers panel

Hide, lock, rename, reorder, and multi-select shapes, text, and images — without leaving the canvas you're working on.

Device-size guides

iPhone, iPad, and common Android phone/tablet/foldable presets, so your exported coordinates match a real screen.

Undo everything

Every edit — including layer reordering and visibility — is a real undo step, all the way back.

Self-contained files

A .bezierpath project is a single JSON file — images and all — easy to version or hand off.

AI assistant

Bring your own Anthropic or OpenAI key and describe what you want — it builds shapes, motion, and timing directly on the canvas using the same tools you'd use by hand.

Smart alignment guides

Drag a point, a text label, or an image near another layer's center — or the canvas's own center — and it snaps into place with a live guide line.

Import anything

SVG markup, a raster image, or an SF Symbol — paths, shapes, groups, and transforms come in as real editable points, or get automatically traced to vector.

Dash & line cap

Round, square, or flat caps, plus adjustable dash length and gap, all in their own section of the inspector.

Numeric fields you can nudge

Arrow up/down steps any value by one — or by a tenth on 0–100% fields — no dragging a slider for a precise number.

Live position & size readout

The mouse's x/y position and the canvas's own width/height show right above the canvas as you work.

Free Draw

Sketch freehand with the mouse and it's automatically simplified and smoothed into a clean, editable curve — no pen-tool precision required.
